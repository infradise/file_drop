# file_drop_example

Desktop testbed application demonstrating `file_drop` native file/directory dialogs and multi-zone window drag-and-drop on macOS, Windows, and Linux.

## Running Locally

From a clone of [`https://github.com/infradise/file_drop`](https://github.com/infradise/file_drop):

```bash
cd example
flutter run -d macos    # or -d windows / -d linux
```
